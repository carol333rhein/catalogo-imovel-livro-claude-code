# A mensagem para enviar ao Claude Code

Abra o Claude Code, copie a mensagem do quadro abaixo e envie. É só isso: o Claude Code baixa o kit e pergunta o resto (título, palavra do comentário, dados e fotos do imóvel).

```
Baixa este kit numa pasta nova (ignora qualquer pasta de projeto que já esteja aberta) e cria o catálogo do meu imóvel seguindo as instruções que estão dentro dele: https://github.com/carol333rhein/catalogo-imovel-livro-claude-code/archive/refs/heads/main.zip

Eu não sei programar: me explica em português simples o que você está fazendo e me avisa quando eu precisar clicar em Permitir.
```

**Antes de postar:** confira os dados do imóvel e as fotos no vídeo. Se as fotos forem criadas por IA, avise no vídeo que o imóvel é ilustrativo.
